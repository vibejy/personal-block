Calendar availability sync

Personal Block

Personal Block is a private automation that mirrors availability from two configured Google Calendars into a separate, app-created calendar. It creates private events titled “Personal Block” with only their start and end times and busy or free status, so a designated work calendar can show availability without revealing the source event details.

How it works

The automation reads the calendar fields needed to choose eligible events and avoid duplicates. It does not copy source event titles, descriptions, locations, or guest lists into Personal Block events. The sync runs locally on its operator’s computer; this website only provides information about the app and does not run the calendar synchronization.
