Personal Block

Privacy Policy

Last updated: October 5, 2026

This policy describes Personal Block, a personal-use calendar sync, and covers Personal Block’s handling of Google Calendar data.

Google data accessed

Personal Block requests Google’s calendar.events.owned.readonly scope to read events on calendars owned by the authorizing account, and calendar.app.created to create, update, or delete events on calendars created by the app. The automation uses these permissions only with its configured source calendars and its Personal Blocks destination calendar.

From source events, it reads event identifiers, status, start and end times, busy or free status, and event type. For eligibility and duplicate checks it also reads limited organizer and attendee email/response fields. It does not request source titles, descriptions, locations, attachments, attendee names, or other guest details.

How data is used and shared

Calendar data is used only to decide which time blocks to create, update, cancel, or skip. Each destination event contains the fixed title “Personal Block,” its start and end times, and busy or free status. Destination events are private and are sent to the configured work-calendar account. Source event names and other descriptive details are not copied.

Calendar data is processed through the Google Calendar API and is subject to Google’s terms and privacy practices, including the Google Privacy Policy. The automation does not send calendar event content to this website or use it for advertising. It may send its operator a Telegram alert with the sync status and last successful sync time; alerts contain no event details.

Storage and retention

OAuth credentials and synchronization state are stored locally on the operator’s computer. The state keeps opaque source and destination event identifiers, a content fingerprint, and an end time so the sync can update or cancel the matching block. It does not store source event titles, descriptions, or locations. After an event has ended, a later successful sync removes its mapping from local state. Events already created in Google Calendar remain there until the calendar owner removes them.

Your controls

You can stop future synchronization by revoking Personal Block’s Google access. Revoking access does not automatically remove blocks already created in Google Calendar; those can be removed from the Personal Blocks calendar by its owner.
